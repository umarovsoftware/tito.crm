# Parfyum Admin Dashboard

React + Vite + TypeScript + Tailwind CSS asosidagi LocalStorage demo admin panel.

## Ishga tushirish

```bash
npm install
npm run dev
```

Production tekshiruvi:

```bash
npm run build
npm run preview
```

Barcha ma'lumotlar brauzer LocalStorage xotirasida saqlanadi. Sozlamalar sahifasidagi tugma demo bazani qayta tiklaydi.

## Yangi modul

- Qarzdorlar — mijozlarning do‘konga qarzi.
- Qarzlarim — do‘konning firma va yetkazib beruvchilarga qarzi. Qarz to‘lovi avtomatik ravishda Chiqimlar bo‘limiga yoziladi.
